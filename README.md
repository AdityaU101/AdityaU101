## About

Graduate student in Computer Science at Arizona State University (May 2027), with a B.S. from CMR Institute of Technology, Bengaluru (May 2025). My focus areas are cloud infrastructure, machine learning, and full-stack development. Lately I've been building AI-powered systems end to end — CloudArch, a multi-cloud architecture generator that outputs deployable IaC, and ClearChart, a RAG + rule-engine medical-report analyzer with a queue-decoupled, horizontally scalable backend. Currently serving as a Course Grader for CSE 460: Software Analysis and Design at ASU. Actively seeking SWE and Cloud Engineering roles.
